## Estado desabilitado

<ComponentEmbed component="Button" variant="disabled" />

- O botão desabilitado continua visível, mas não recebe foco.
- Explique **por que** a ação está indisponível perto do botão:
  1. num texto de apoio;
  2. ou numa mensagem de validação.

<Callout variant="warning">
  Não use cor como único sinal de estado.

  <DosDonts variant="do" title="Texto + cor">
    "Preencha o e-mail para continuar" ao lado do botão.
  </DosDonts>
</Callout>
