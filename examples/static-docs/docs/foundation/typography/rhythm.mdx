## Entrelinha

A entrelinha é um número sem unidade — multiplica o tamanho da fonte, então acompanha o texto em qualquer tamanho. Títulos usam `tight`; texto corrido, `normal`.

## Espaçamento entre letras

Quanto maior o texto, mais apertado; quanto menor, mais aberto. Rótulos em maiúsculas usam `caps`, em `em`, para acompanhar o tamanho da fonte.
