## Princípios

O desfoque (`backdrop-filter: blur(…)`) separa uma superfície translúcida do que está atrás sem escondê-lo por inteiro. Combine sempre com uma cor de fundo semitransparente: só o desfoque não garante contraste para o texto por cima.

| Token | Valor | Uso |
| --- | --- | --- |
| `acme.blur.sm` | 4px | Menus translúcidos |
| `acme.blur.md` | 8px | Fundo atrás de modais |
| `acme.blur.lg` | 16px | Imagem de capa sob texto |
