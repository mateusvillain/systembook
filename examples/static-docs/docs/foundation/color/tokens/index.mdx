Os tokens de cor são variáveis CSS definidas na raiz do documento. Esta página tem tabs: o **Overview** é este arquivo (`index.mdx`), e as tabs são os outros arquivos da pasta.

## Nomenclatura

Todo token segue o padrão `--acme-<papel>[-<variação>]`:

- `--acme-primary`
- `--acme-primary-hover`
- `--acme-neutral-subtle`
