## Estilo do traço

`solid` é o padrão; os outros estilos carregam significado e não devem ser usados só para enfeitar.

| Token | Uso |
| --- | --- |
| `acme.border.style.solid` | Bordas e divisores |
| `acme.border.style.dashed` | Área de soltar arquivos, rascunhos |
| `acme.border.style.dotted` | Sublinhado de termo com definição |
| `acme.border.style.focus` | Contorno de seleção múltipla (traço e espaço sob medida) |

<Callout variant="info">
  `acme.border.style.focus` define o tamanho de cada traço (`dashArray`), o que o `border-style` do CSS não representa: numa borda CSS ele vira `dashed`. Para o traço exato, use SVG (`stroke-dasharray`) — é o que a amostra da tabela mostra.
</Callout>
